## 我能写什么

| 层 | 具体 |
|---|---|
| **前端** | 原生 JS（不依赖框架）、CSS、WebView 内嵌、响应式布局 |
| **后端** | Python `http.server` 手写路由、SSE 流式输出、多后端路由、会话状态持久化 |
| **插件 / 工具链** | Node.js 插件、cordis 钩子、策略引擎、审计账本 |
| **移动端** | Android 原生（Java）、悬浮窗服务、APK 构建与签名 |
| **脚本 / 自动化** | PowerShell、计划任务、无人值守任务链 |

**共同点**：五个项目里四个是零第三方依赖 —— 不用 Flask、不用 React、不用任何构建工具。
这不是为了炫技，是因为我想让「拷到任何一台机器上双击就能跑」这件事成立。

## 我在意的事

- **不联网也能用**：数据留在本机，不上传
- **零安装成本**：能拷走就跑，不折腾环境
- **说清楚边界**：防护插件不是杀软、工具不是万能的，README 里先写清楚它做不到什么
- **有测试**：象数工坊 424 项、alpha-guard 自检、跑团 17 个测试脚本
